# Icon Files Required

The following icon files are required for the webOS app:

1. **icon.png** (80x80 pixels)
   - App icon for the launcher
   - PNG format with transparency
   - Place in the root directory

2. **largeIcon.png** (130x130 pixels)
   - Large icon for the launcher
   - PNG format with transparency
   - Place in the root directory

## Design Guidelines

- Use a dark background (#1c2331 or similar)
- Include a play button or streaming icon
- Keep it simple and recognizable at small sizes
- Follow webOS design guidelines: https://webostv.developer.lge.com/design-guidelines/

## Example

You can create simple icons using:
- Online tools: https://www.favicon-generator.org/
- Image editors: GIMP, Photoshop, etc.
- SVG to PNG converters

For development/testing, you can use placeholder icons from the webOS SDK examples.
